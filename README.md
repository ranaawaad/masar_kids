# 🧭 تطبيق مسار | Masar App

**مسار (Masar)** هو تطبيق ويب تفاعلي مبسط (MVP) تم بناؤه باستخدام لغة بايثون ومكتبة **Streamlit**. يهدف التطبيق لمساعدة أولياء الأمور في توجيه أطفالهم والشباب نحو قنوات يوتيوب ومنصات تعليمية وتثقيفية هادفة وموثوقة بناءً على الفئات العمرية واهتماماتهم الشخصية، لحمايتهم من المحتوى غير المفيد وتطوير مهاراتهم للمستقبل.

---

## 🎨 مميزات التطبيق (UI/UX Features)
*   **تصميم عصري فائق الجمال (Mobile-First Glassmorphism)**: واجهة مستخدم حديثة بأسلوب الزجاج الضبابي تتناسب تماماً مع الهواتف المحمولة والشاشات المختلفة.
*   **لوحة إحصائيات تفاعلية (4 Metrics Dashboard)**: عرض ديناميكي لعدد القنوات المعتمدة، مجالات الاهتمام، القنوات المحفوظة، ونسبة الأمان.
*   **وسوم تفاعلية (Tag Chips & Platform Types)**: عرض شارات توضيحية لنوع المنصة (قناة يوتيوب 📺، بودكاست 🎙️، تطبيق 🌐) بالإضافة لوسوم المواضيع (`#برمجة` `#علوم` `#أخلاق`).
*   **نظام السمات المتعددة (Dynamic Themes)**: يتيح التبديل بين 4 سمات بصرية مذهلة (سماوي كلاسيكي 🌊، غروب دافئ 🌅، نعناع هادئ 🌿، فضاء مظلم 🌌) مع وضع ليلي كامل.
*   **بوابة التحقق الأبوية (Parental Gate)**: تحدٍ رياضي ذكي مدمج باستخدام نافذة `@st.dialog` لحماية وصول الأطفال لتبويب أولياء الأمور وإعدادات الأمان.
*   **مزامنة روابط التصفح (Deep Linking)**: يعتمد على `st.query_params` لحفظ الفئة العمرية والاهتمامات في الرابط ومشاركتها مباشرة.
*   **محرك بحث ذكي وسريع (Smart Search Engine)**: بحث فوري بالكلمات المفتاحية والوسوم والقنوات سواءً في القسم الحالي أو عبر كافة الفئات العمرية.
*   **تصدير ومشاركة المفضلة (WhatsApp & Clipboard Export)**: تصدير قائمة القنوات المحفوظة بنقرة واحدة كرسالة جاهزة للمشاركة الفورية عبر WhatsApp.
*   **نصيحة اليوم التربوية (Parental Tips)**: نصائح متجددة وعشوائية لمساعدة الآباء في إدارة وقت شاشات أطفالهم مع زر التحديث الفوري.
*   **خطوط عربية أنيقة واستقرار RTL**: استخدام خط **Cairo** المتميز والاعتماد على الخصائص المنطقية في CSS لضمان استقرار المحاذاة العربية.

## 🛠️ التكنولوجيا المستخدمة (Tech Stack)
*   **لغة البرمجة**: Python 3.8+
*   **واجهة المستخدم والمنطق**: Streamlit 1.35.0+
*   **التنسيق البصري**: HTML5 & CSS3 مخصص لدعم اتجاه النصوص من اليمين إلى اليسار (RTL).

## 🚀 طريقة التشغيل محلياً (How to Run Locally)

### 1. تحميل المشروع والانتقال للمجلد
```bash
git clone https://github.com/ranaawaad/masar_kids.git
cd masar_kids
```

### 2. إنشاء بيئة عمل افتراضية وتفعيلها
*   **على نظام ويندوز (Windows)**:
    ```bash
    python -m venv venv
    venv\Scripts\activate
    ```
*   **على أنظمة ماك/لينكس (Mac/Linux)**:
    ```bash
    python3 -m venv venv
    source venv/bin/activate
    ```

### 3. تثبيت المكتبات المطلوبة
```bash
pip install -r requirements.txt
```

### 4. تشغيل التطبيق
```bash
streamlit run app.py
```

سيفتح المتصفح تلقائياً ويعرض الواجهة التفاعلية على الرابط المحلي: `http://localhost:8501`.

## 📂 هيكلية المشروع (Project Structure)
*   `app.py`: ملف التطبيق الرئيسي الذي يدير الواجهة البرمجية والتفاعلية والتنسيقات البصرية.
*   `channels_data.py`: قاعدة البيانات المنسقة التي تحتوي على تفاصيل القنوات، الروابط، والوسوم.
*   `requirements.txt`: ملف التبعيات والمكتبات البرمجية.
*   `masar_logo.png`: شعار التطبيق البصري.
*   `README.md`: ملف التوثيق المحدث للمشروع.
